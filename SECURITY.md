# Reporting a vulnerability

Please report issues privately through [GitHub private vulnerability reporting](https://github.com/ZeroClave/langfuse-privacy/security/advisories/new) when enabled. If that channel is unavailable, open an issue requesting a private contact without including exploit details, credentials, personal data, or production traces.

The initial alpha implementation is the currently maintained version. Include the package version, Node/Langfuse versions, affected masking path, and a minimal example with synthetic data. See the README for detection-service trust boundaries and hook coverage.
